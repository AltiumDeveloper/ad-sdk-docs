# Calling the Altium 365 API

An extension calls the [Altium 365 API](https://docs.developer.altium.com/platform-api-docs/), a GraphQL API for
workspace data, as the user who is signed in to Altium Designer, without an application registration of its own.
Altium Designer 26.12 provides the endpoint and an access token for the connected workspace (see [Versions](#versions)).

## The endpoint, the token and the workspace

All three come from the server manager, `EDP.Utils.GetDXPServerManager()` (`DXP.IEDMS_DXPServerManager`):

| What | Call | Example value |
| --- | --- | --- |
| Signed in? | `server.IsConnected()` | `true` |
| The API endpoint | `server.GetDiscoveryService().GetServiceURL("PLATFORMAPI")` | `https://eur.365.altium.com/napi/gateway/graphql/` |
| The access token | `server.GetSessionID()` | a JWT, used as `Authorization: Bearer <token>` |
| The workspace | the host of `server.GetDiscoveryService().VaultUrl()` | `acme.365.altium.com` |

- **The endpoint** is the GraphQL endpoint of the region that hosts the connected workspace. Use it as returned; do
  not choose a regional endpoint yourself.
- **The token** is an access token (a JWT) for the signed-in user's session: it gives access to the connected
  workspace as that user. It carries its expiry time (the `exp` claim): reuse it until it expires, then call
  `GetSessionID()` again.
- **The workspace** is the one Altium Designer is signed in to. `desProjects` without its `workspaceUrl` argument
  returns that workspace's projects. `desWorkspaceInfos` lists all of the user's workspaces; the connected one has the
  same host as the Vault URL. The token reaches only that workspace: a query for another one
  (`desProjects(workspaceUrl: …)` with another workspace's URL) fails with "Cannot access workspace: The workspace
  identifier in the access token does not match the requested workspace."

## A first query

This command lists the connected workspace and its projects. Send the request off the main thread and wait for it, so
that waiting does not block Altium Designer's message loop:

```csharp
using System;
using System.Net.Http;
using System.Net.Http.Headers;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;
using DXP;
using EDP;

static class Altium365
{
    const string Query =
        "query { desWorkspaceInfos { name url workspaceId } desProjects(first: 10) { totalCount nodes { name projectId } } }";

    public static string ListProjects()
    {
        IEDMS_DXPServerManager server = EDP.Utils.GetDXPServerManager();
        if (server == null || !server.IsConnected())
            return "Altium Designer is not signed in to a workspace.";

        IEDMS_DiscoveryServiceManager discovery = server.GetDiscoveryService();
        string endpoint = discovery.GetServiceURL("PLATFORMAPI");
        string workspaceHost = new Uri(discovery.VaultUrl()).Host;

        using JsonDocument result = Post(endpoint, server.GetSessionID(), Query);
        JsonElement data = result.RootElement.GetProperty("data");

        var text = new StringBuilder();
        foreach (JsonElement workspace in data.GetProperty("desWorkspaceInfos").EnumerateArray())
        {
            string url = workspace.GetProperty("url").GetString();
            if (string.Equals(new Uri(url).Host, workspaceHost, StringComparison.OrdinalIgnoreCase))
                text.AppendLine($"Workspace: {workspace.GetProperty("name").GetString()} {url}");
        }
        JsonElement projects = data.GetProperty("desProjects");
        text.AppendLine($"Projects: {projects.GetProperty("totalCount").GetInt32()}");
        foreach (JsonElement project in projects.GetProperty("nodes").EnumerateArray())
            text.AppendLine($"  {project.GetProperty("name").GetString()}");
        return text.ToString();
    }

    static JsonDocument Post(string endpoint, string token, string query)
    {
        using var http = new HttpClient { Timeout = TimeSpan.FromSeconds(30) };
        using var request = new HttpRequestMessage(HttpMethod.Post, endpoint)
        {
            Content = new StringContent(JsonSerializer.Serialize(new { query }), Encoding.UTF8, "application/json"),
        };
        request.Headers.Authorization = new AuthenticationHeaderValue("Bearer", token);

        (int status, string body) = Task.Run(async () =>
        {
            using HttpResponseMessage response = await http.SendAsync(request).ConfigureAwait(false);
            return ((int)response.StatusCode, await response.Content.ReadAsStringAsync().ConfigureAwait(false));
        }).GetAwaiter().GetResult();

        // Read the errors before the status: a query that does not match the schema comes back with status 400.
        JsonDocument json;
        try
        {
            json = JsonDocument.Parse(body);
        }
        catch (JsonException)
        {
            throw new InvalidOperationException($"Altium 365 API: HTTP {status}, the response is not JSON");
        }
        if (json.RootElement.TryGetProperty("errors", out JsonElement errors) && errors.GetArrayLength() > 0)
        {
            string message = errors[0].GetProperty("message").GetString();
            json.Dispose();
            throw new InvalidOperationException("Altium 365 API: " + message);
        }
        if (status != 200)
        {
            json.Dispose();
            throw new InvalidOperationException($"Altium 365 API: HTTP {status}");
        }
        return json;
    }
}
```

The API reports errors in the response body, in its `errors` member: with HTTP status 200 when the query is valid but
fails, and with status 400 when the query does not match the schema (an unknown field, for example). Read the body
before checking the status, as `Post` does. Each error has a `message`, and can have a `path` (the field that failed)
and an `extensions.code` (such as `HC0018`). An invalid or expired token gives the error code `AuthInvalidToken` or
`AuthExpiredToken`. The
[Altium 365 API documentation](https://docs.developer.altium.com/platform-api-docs/) has the schema, its types and more
examples; its Nitro IDE (`https://<workspace host>/api/graphql/`) helps to write queries.

## The open project in the API

The Altium 365 API identifies a project by its
[GRID](https://docs.developer.altium.com/cdm/grid-format/), which combines the workspace and the project:
`grid:workspace:<workspace GUID>:design:project/<project GUID>`. A project that is stored in a workspace knows both
GUIDs. They come from the project's `DXP.IDXPProject`, which `DXP.IDXPWorkSpace.DM_FocusedProject` returns for the
focused project; build the GRID from them before calling a query that takes a project, such as
`desProjectById(id:)` or `desCommentThreads(projectId:)`:

```csharp
DXP.IDXPProject project = DXP.GlobalVars.DXPWorkSpace.DM_FocusedProject();
string grid = $"grid:workspace:{project.DM_VaultGUID()}:design:project/{project.DM_ManagedProjectGUID()}";
```

GRIDs are case-sensitive: use both GUIDs as Altium Designer returns them. A query given the project GUID alone fails
("The ID `<GUID>` has an invalid format", or "Cannot return null for non-nullable field"). The token reaches only the
connected workspace (see [The endpoint, the token and the workspace](#the-endpoint-the-token-and-the-workspace)), so
a project stored in another workspace cannot be read until the user signs in to that one.

## Comments

`desCommentThreads(projectId:)`, with the project's GRID, returns the project's comment threads. Each thread
(`DesCommentThread`) has its `comments` (`DesComment`): the first comment and its replies, each with `createdAt`,
`createdBy` (a `DesUser`) and `text`.

```text
query($p: ID!) {
  desCommentThreads(projectId: $p) {
    threadNumber createdAt
    comments { createdAt text createdBy { firstName lastName userName } }
  }
}
```

A project without comments returns an empty list.

## Project history

The `revisions` of a `DesProject` (`desProjectById(id:)` with the project's GRID) are the commits of the project's
repository in the workspace: `totalCount` and, per revision (`DesVcsRevision`), `revisionId`, `author`, `createdAt` and
`message`. The connection is paged: pass `first:` and follow `pageInfo` to read more. `createdAt` is in UTC.

```text
query($id: ID!) {
  desProjectById(id: $id) { name revisions { totalCount nodes { createdAt author message } } }
}
```

The revisions are what has been pushed to the workspace. Commits that are only in the local working copy are not in
the list; read them from the working copy.

## The token is the user's

The token carries the signed-in user's access to the workspace. Never write it to a log, a message, a file or a
setting, and send it only to the endpoint that `GetServiceURL("PLATFORMAPI")` returns.

## Versions

| Altium Designer | `GetSessionID()` returns | The API accepts it |
| --- | --- | --- |
| 26.1 | a session ID of the workspace's other services (not a JWT) | no: `AuthInvalidToken` |
| 26.12 | a JWT access token for the connected workspace | yes |

To support both, check the token before using it: a JWT has three parts separated by dots.
