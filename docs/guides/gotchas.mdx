# Gotchas

| Surprise | Explained in |
| --- | --- |
| An extension copied into the `Extensions` folder never loads, and nothing reports it: register it in `ExtensionsRegistry.xml`. | [Getting started](./getting-started.mdx#registering-the-extension) |
| A project's BOM manager casts to `IActiveBomManager`, but its ActiveBOM members fail with "Interface not supported". | [Working with bills of materials](./bom.mdx#getting-a-bom) |
| `obj is IPCB_Region` and `as` succeed for every object; calling a member the object lacks throws a `COMException`. Branch on `IPCB_Primitive.ObjectID` or `ISch_BasicContainer.ObjectId`. | [Interfaces at run time](./interfaces-at-run-time.mdx#type-tests-succeed-for-every-object) |
| A typed member such as `GetState_ObjectID()` does not exist: add `using DXP; using EDP; using PCB; using SCH;`. | [Interfaces at run time](./interfaces-at-run-time.mdx#typed-helpers-need-their-namespace) |
| A reference kept from an earlier command fails. Get the workspace, project, document or board again in each command. | [Interfaces at run time](./interfaces-at-run-time.mdx#get-references-again-in-each-command) |
| Every iterator must be destroyed, also when the loop ends early. | [Interfaces at run time](./interfaces-at-run-time.mdx#destroy-every-iterator) |
| SDK calls from a background thread: call the API only on the main thread, and post work back to it. | [Runtime and hosting](./runtime-and-hosting.mdx#the-main-thread) |
| The project generator creates a .NET Framework 4.8 project; Altium Designer hosts .NET 8 (26.1) or .NET 10 (26.12). | [Project setup](./project-setup.mdx) |
| After an Altium Designer update the extension no longer builds (CS1705, `System.Runtime, Version=10.0.0.0`): the hosted .NET version changed; retarget the project. | [Runtime and hosting](./runtime-and-hosting.mdx#the-net-runtime) |
| `Altium.SDK.dll` copied to the extension's folder, or referenced from the wrong folder: reference it from the installation's `System` folder, without copying it. | [Project setup](./project-setup.mdx) |
| A change to the `.ins` file, the `.rcs` file or the extension assembly does nothing until Altium Designer restarts. | [Development loop](./development-loop.mdx#what-needs-a-restart) |
| A top-level menu inserted into the schematic or PCB menus never appears, although the commands work: add `Updates = '<server>'` to the `Server` block of the `.ins` file. | [Menus and the .rcs file](./menus.mdx#inserting-into-other-menus) |
| The extension's code (and any pipe server or hot-reload host it starts) runs only after its first command in a session. | [Development loop](./development-loop.mdx#when-the-extension-starts) |
| A `runtimeconfig.json` in the extension's folder, or `$_` used as the file inside a PowerShell `catch` block of a deployment script. | [Development loop](./development-loop.mdx#what-needs-a-restart) |
| A hot-reloaded build stays in memory: WPF keeps every newly loaded assembly. | [Runtime and hosting](./runtime-and-hosting.mdx#frameworks-in-the-process) |
| Menu items go in the `.rcs` file, command declarations in the `.ins` file; `Params` arrives as the command's `ref string` parameter. | [Menus and the .rcs file](./menus.mdx) |
| Double-clicking a message runs its callback process, which can be the extension's own command. | [The Messages panel](./messages-panel.mdx#navigating-on-double-click) |
| `IPart.DM_LibraryReference` is not the workspace item ID (`CMP-…`); that is the `Library Reference` parameter. | [Design data notes](./design-data-notes.mdx#library-references-and-workspace-item-ids) |
| Workspace components have no manufacturer or part number parameters: that data is in Part Choices. | [Design data notes](./design-data-notes.mdx#manufacturer-data-of-workspace-components) |
| PCB coordinates are absolute, in units of 1/10,000 mil: subtract the board origin. | [Working with PCBs](./pcb-basics.mdx#coordinates) |
